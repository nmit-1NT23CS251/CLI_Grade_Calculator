# CLI Grade Calculator

## Week 1 Mini Project - Python

A simple command-line Grade Calculator developed using Python.  
The project demonstrates core Week 1 Python fundamentals such as functions, loops, dictionaries, conditional statements, and exception handling.

## Features

- Accepts student name
- Accepts marks for multiple subjects
- Validates marks between 0 and 100
- Calculates total marks
- Calculates average marks
- Assigns a grade based on the average
- Determines Pass/Fail status
- Allows calculation for multiple students
- Handles invalid input using exception handling

## Python Concepts Used

- Variables and Data Types
- Lists
- Dictionaries
- Functions
- For Loops
- While Loops
- If / Elif / Else
- Operators
- Input and Output
- Try / Except
- String Methods

## Grade Criteria
90 - 100 ->  A+ 
80 - 89  ->  A 
70 - 79  ->  B 
60 - 69  ->  C 
50 - 59  ->  D 
Below 50 ->  F 

A student is considered **FAIL** if they score below 35 in any subject.
